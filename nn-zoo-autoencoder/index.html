Overview

An Autoencoder is a neural network trained to reconstruct its input through a bottleneck layer, forcing it to learn a compressed representation. First explored by Rumelhart, Hinton, and Williams (1986) as a way to learn internal representations, autoencoders have become fundamental to unsupervised feature learning and generative modeling.

The architecture consists of two mirrored halves: an encoder that compresses the input into a low-dimensional latent space, and a decoder that reconstructs the original input from this compressed representation. The bottleneck forces the network to capture only the most salient features.

Key Innovation

By constraining the network to pass information through a bottleneck, autoencoders learn meaningful data representations without labeled training data. Variants like denoising and variational autoencoders extend this idea to robust feature learning and generative modeling.

Common Use Cases

  • Dimensionality reduction — non-linear alternative to PCA
  • Denoising — learning to reconstruct clean data from noisy inputs
  • Anomaly detection — high reconstruction error signals anomalies
  • Feature learning — latent representations for downstream tasks
  • Image compression — learned lossy compression schemes

Limitations

  • May learn trivial identity mapping if bottleneck is too wide
  • Standard autoencoders cannot generate new data (unlike VAEs)
  • Reconstruction loss may not capture perceptual similarity
  • Latent space may not be smooth or structured without regularization

Layer-by-Layer Breakdown

Click on any layer in the diagram above to highlight its description below.

Input Layer
Shape: [batch_size, input_dim]

The original data to be encoded. For images, this is typically a flattened pixel vector (e.g., 784 for MNIST 28x28). The goal is to reconstruct this exactly at the output.

Encoder (Dense + ReLU)
Progressively reduces dimensionality

One or more dense layers that progressively compress the input. Each layer reduces the dimension, forcing the network to learn which features are most important to preserve. Deeper encoders can learn more abstract representations.

Latent Space (Bottleneck)
Shape: [batch_size, latent_dim] · The compressed representation

The narrowest layer, representing the compressed encoding. The dimensionality of this layer (latent_dim) controls the compression ratio. Smaller values force more compression but may lose detail. This is the learned representation of the input.

Decoder (Dense + ReLU)
Mirrors the encoder architecture

Symmetric to the encoder, the decoder progressively expands the latent representation back to the original dimensionality. It learns to reconstruct the input from the compressed code.

Output (Reconstruction)
Shape: [batch_size, input_dim] · Sigmoid activation

The reconstructed output, same dimensionality as the input. Sigmoid activation is used for normalized inputs (0-1 range). The difference between input and output is the reconstruction error, which drives training.

Key Equations

Encoder

$$\mathbf{z} = f_\theta(\mathbf{x}) = \sigma(\mathbf{W}_e \mathbf{x} + \mathbf{b}_e)$$

Maps input x to latent representation z through learnable weights W_e and bias b_e with activation σ.

Decoder

$$\hat{\mathbf{x}} = g_\phi(\mathbf{z}) = \sigma(\mathbf{W}_d \mathbf{z} + \mathbf{b}_d)$$

Reconstructs input from latent code z. The output should match the original input as closely as possible.

Reconstruction Loss (MSE)

$$\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N} \|\mathbf{x}_i - \hat{\mathbf{x}}_i\|^2$$

Mean squared error between original input and reconstruction. Minimizing this forces the network to learn useful compressed representations.

Binary Cross-Entropy Loss (alternative)

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\left[\mathbf{x}_i \log(\hat{\mathbf{x}}_i) + (1-\mathbf{x}_i)\log(1-\hat{\mathbf{x}}_i)\right]$$

Used when inputs are binary or normalized to [0, 1] (common for image data with sigmoid output).

Compression Ratio

$$\text{ratio} = \frac{d_{input}}{d_{latent}}$$

The ratio of input dimensionality to latent dimensionality. Higher ratios mean more compression.

Implementation

PyTorch

import torch
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, input_dim=784, latent_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 64),
            nn.ReLU(),
            nn.Linear(64, latent_dim),
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 256),
            nn.ReLU(),
            nn.Linear(256, input_dim),
            nn.Sigmoid(),
        )

    def forward(self, x):
        z = self.encoder(x)
        reconstructed = self.decoder(z)
        return reconstructed

    def encode(self, x):
        return self.encoder(x)

model = Autoencoder()
x = torch.randn(32, 784)  # batch of 32 flattened MNIST images
output = model(x)           # shape: [32, 784]
loss = nn.MSELoss()(output, x)

TensorFlow / Keras

import tensorflow as tf
from tensorflow import keras

encoder = keras.Sequential([
    keras.layers.Dense(256, activation='relu', input_shape=(784,)),
    keras.layers.Dense(64, activation='relu'),
    keras.layers.Dense(32),  # latent space
])

decoder = keras.Sequential([
    keras.layers.Dense(64, activation='relu', input_shape=(32,)),
    keras.layers.Dense(256, activation='relu'),
    keras.layers.Dense(784, activation='sigmoid'),
])

# Combined model
inputs = keras.Input(shape=(784,))
z = encoder(inputs)
reconstructed = decoder(z)
autoencoder = keras.Model(inputs, reconstructed)

autoencoder.compile(optimizer='adam', loss='mse')

NumPy (From Scratch)

import numpy as np

def relu(x): return np.maximum(0, x)
def sigmoid(x): return 1 / (1 + np.exp(-np.clip(x, -500, 500)))

class SimpleAutoencoder:
    def __init__(self, dims):
        # dims = [784, 256, 64, 32, 64, 256, 784]
        self.weights = []
        self.biases = []
        for i in range(len(dims) - 1):
            w = np.random.randn(dims[i], dims[i+1]) * 0.01
            b = np.zeros((1, dims[i+1]))
            self.weights.append(w)
            self.biases.append(b)

    def forward(self, x):
        a = x
        mid = len(self.weights) // 2
        for i, (w, b) in enumerate(zip(self.weights, self.biases)):
            z = a @ w + b
            if i == len(self.weights) - 1:
                a = sigmoid(z)
            else:
                a = relu(z)
        return a

ae = SimpleAutoencoder([784, 256, 64, 32, 64, 256, 784])
x = np.random.rand(1, 784)
reconstructed = ae.forward(x)
