Overview

The Recurrent Neural Network (RNN) is a class of neural networks designed for processing sequential data. Unlike feedforward networks that treat each input independently, RNNs maintain a hidden state that is updated at each time step, allowing information to persist across the sequence. This makes them naturally suited for tasks where context and order matter.

At each time step, the RNN receives an input vector and combines it with the previous hidden state to produce a new hidden state and, optionally, an output. The same set of weights is applied at every time step — a property known as weight sharing — which allows the network to generalize across different sequence positions and handle variable-length inputs.

Key Innovation

The core idea is that the hidden state acts as a form of memory, carrying forward a compressed summary of all previously seen inputs. By sharing weights across time steps, RNNs can process sequences of arbitrary length with a fixed number of parameters. Training is performed via Backpropagation Through Time (BPTT), which unrolls the network across time steps and computes gradients through the entire sequence.

Common Use Cases

  • Time series prediction — forecasting stock prices, weather, sensor readings
  • Language modeling — predicting the next word in a sequence
  • Speech recognition — transcribing audio waveforms to text
  • Music generation — composing melodies note by note
  • Sequence-to-sequence tasks — machine translation, text summarization

Limitations

  • Vanishing gradients — gradients shrink exponentially during BPTT, making it difficult to learn long-range dependencies
  • Exploding gradients — gradients can also grow uncontrollably, requiring gradient clipping
  • Short-term memory bias — in practice, vanilla RNNs struggle to remember information from more than ~10–20 time steps ago
  • Sequential processing — time steps must be processed in order, preventing parallelization (unlike Transformers)
  • Superseded by LSTM/GRU — gated variants address the vanishing gradient problem and are preferred in most applications

Layer-by-Layer Breakdown

Input Layer
Shape: [batch_size, seq_len, n_features]

The input is a sequence of vectors, one per time step. Each vector has n_features dimensions. For example, in language modeling each input might be a word embedding vector, while in time series each input could be a single scalar measurement. The full input tensor has shape [batch, sequence length, features].

RNN Cell
Params: W_xh (n_features × hidden_size) + W_hh (hidden_size × hidden_size) + b_h

The RNN cell is the core computation unit, applied identically at every time step. It takes the current input x_t and the previous hidden state h_{t-1}, multiplies each by its respective weight matrix, sums them with a bias, and applies a tanh activation. The same weights W_xh, W_hh, and b_h are reused at every time step.

Hidden State
Shape: [batch_size, hidden_size]

The hidden state is a vector that carries information across time steps. It serves as the network's memory, encoding a compressed summary of the sequence processed so far. At each step, the hidden state is updated based on the new input and the previous hidden state. The initial hidden state h_0 is typically initialized to zeros.

Output Layer
Shape: [batch_size, output_size] (per step or final only)

The output at each time step is computed from the hidden state via a linear transformation W_hy h_t + b_y. Depending on the task, the network may produce an output at every time step (e.g., language modeling) or only at the final step (e.g., sentiment classification). For sequence-to-sequence tasks, all outputs are used.

Dense / Softmax
Params: W_hy (hidden_size × n_classes) + b_y

The final dense layer projects the hidden state (or output) into the target space. For classification, a softmax activation converts raw logits into a probability distribution over classes. For regression, a linear activation is used. In many-to-one tasks, only the last hidden state is fed to this layer.

Key Equations

Hidden State Update

$$h_t = \tanh(W_{hh} \, h_{t-1} + W_{xh} \, x_t + b_h)$$

At each time step t, the hidden state ht is computed by applying the tanh activation to a linear combination of the previous hidden state ht-1 and the current input xt. The matrices Whh (hidden-to-hidden) and Wxh (input-to-hidden) are shared across all time steps.

Output Computation

$$y_t = W_{hy} \, h_t + b_y$$

The output at each time step is a linear projection of the hidden state. For classification tasks, a softmax is applied on top: $\hat{y}_t = \text{softmax}(y_t)$.

Backpropagation Through Time (BPTT)

$$\frac{\partial \mathcal{L}}{\partial W_{hh}} = \sum_{t=1}^{T} \frac{\partial \mathcal{L}_t}{\partial W_{hh}} = \sum_{t=1}^{T} \sum_{k=1}^{t} \frac{\partial \mathcal{L}_t}{\partial h_t} \left(\prod_{j=k+1}^{t} \frac{\partial h_j}{\partial h_{j-1}}\right) \frac{\partial h_k}{\partial W_{hh}}$$

BPTT unrolls the RNN across all time steps and applies the chain rule backward through time. The product of Jacobians $\prod \frac{\partial h_j}{\partial h_{j-1}}$ is the source of the vanishing/exploding gradient problem: if the spectral radius of $W_{hh}$ is less than 1, gradients shrink exponentially; if greater than 1, they explode.

Cross-Entropy Loss (Sequence)

$$\mathcal{L} = -\frac{1}{T}\sum_{t=1}^{T}\sum_{c=1}^{C} y_{t,c} \log(\hat{y}_{t,c})$$

For sequence classification, the loss is averaged over all time steps T and all classes C. For many-to-one tasks, only the final time step contributes to the loss.

Implementation

PyTorch

import torch
import torch.nn as nn

class SimpleRNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size, num_layers=1):
        super().__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        self.rnn = nn.RNN(input_size, hidden_size,
                          num_layers=num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        # x shape: [batch, seq_len, input_size]
        h0 = torch.zeros(self.num_layers, x.size(0),
                          self.hidden_size).to(x.device)
        out, h_n = self.rnn(x, h0)
        # out shape: [batch, seq_len, hidden_size]
        # Use last time step for classification
        out = self.fc(out[:, -1, :])
        return out

# Example usage
model = SimpleRNN(input_size=10, hidden_size=32, output_size=5)
x = torch.randn(8, 20, 10)  # batch=8, seq_len=20, features=10
output = model(x)             # shape: [8, 5]

NumPy (From Scratch)

import numpy as np

def tanh(z):
    return np.tanh(z)

class RNNCell:
    def __init__(self, input_size, hidden_size):
        scale = 0.01
        self.W_xh = np.random.randn(input_size, hidden_size) * scale
        self.W_hh = np.random.randn(hidden_size, hidden_size) * scale
        self.b_h = np.zeros((1, hidden_size))

    def step(self, x_t, h_prev):
        """Single time step: h_t = tanh(x_t @ W_xh + h_prev @ W_hh + b_h)"""
        h_t = tanh(x_t @ self.W_xh + h_prev @ self.W_hh + self.b_h)
        return h_t

    def forward(self, x_seq):
        """Process full sequence: x_seq shape [seq_len, input_size]"""
        seq_len = x_seq.shape[0]
        hidden_size = self.W_hh.shape[0]
        h = np.zeros((1, hidden_size))
        hidden_states = []
        for t in range(seq_len):
            h = self.step(x_seq[t:t+1], h)
            hidden_states.append(h)
        return np.vstack(hidden_states), h

# Example
cell = RNNCell(input_size=10, hidden_size=32)
x_seq = np.random.randn(20, 10)  # 20 time steps, 10 features
all_h, final_h = cell.forward(x_seq)
print(all_h.shape)   # (20, 32)
print(final_h.shape)  # (1, 32)

Key Papers

Learning representations by back-propagating errors
Rumelhart, Hinton & Williams, 1986 — Introduced backpropagation for training multi-layer networks, the foundation for training RNNs
Finding Structure in Time
Jeffrey L. Elman, 1990 — Introduced the Elman network (simple RNN), demonstrating that recurrent connections can learn temporal structure
Learning Long-Term Dependencies with Gradient Descent is Difficult
Bengio, Simard & Frasconi, 1994 — Formally characterized the vanishing gradient problem in RNNs, motivating gated architectures
Long Short-Term Memory
Hochreiter & Schmidhuber, 1997 — Proposed LSTM gating mechanism to solve the vanishing gradient problem in RNNs

Related Architectures

The vanilla RNN is the foundation upon which these architectures build:

  • LSTM — Adds input, forget, and output gates to control information flow and solve vanishing gradients
  • GRU — A simplified gated RNN with reset and update gates, fewer parameters than LSTM
  • Seq2Seq — Encoder-decoder architecture using RNNs for sequence-to-sequence tasks like translation
  • Transformer — Replaces recurrence with self-attention, enabling full parallelization
