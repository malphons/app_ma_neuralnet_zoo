Overview

The Long Short-Term Memory (LSTM) network was introduced by Hochreiter and Schmidhuber in 1997 to address the vanishing gradient problem that plagues standard RNNs. By introducing a gated cell state that can selectively remember or forget information over long time intervals, LSTMs became the dominant architecture for sequence modeling tasks for nearly two decades.

The key insight is the cell state — a highway that runs through the entire chain with only minor linear interactions. Three gates (forget, input, output) control the flow of information into, within, and out of the cell, allowing the network to learn which information to retain over hundreds of time steps.

Key Innovation

The gating mechanism allows gradients to flow unchanged through the cell state, solving the vanishing gradient problem. Each gate is a sigmoid layer that outputs values between 0 and 1, controlling how much information passes through.

Common Use Cases

  • Machine translation — encoding source sentences and decoding target sentences
  • Text generation — character-level and word-level language modeling
  • Speech recognition — processing audio spectrograms over time
  • Time series forecasting — financial data, weather, sensor readings
  • Music generation — learning temporal patterns in musical sequences

Limitations

  • Sequential processing prevents parallelization (slower training than Transformers)
  • Still struggles with very long sequences (1000+ steps)
  • More parameters than simple RNNs (4x weight matrices per cell)
  • Largely superseded by Transformer architectures for NLP tasks

Layer-by-Layer Breakdown

Click on any layer in the diagram above to highlight its description below.

Input (x_t)
Shape: [batch_size, seq_length, input_dim]

The input at each time step. For text, this is typically a word embedding vector. The LSTM processes one time step at a time, receiving x_t along with the previous hidden state h_{t-1} and cell state c_{t-1}.

Forget Gate (f_t)
Activation: sigmoid · Output: [0, 1] per cell unit

Decides what information to discard from the cell state. Takes h_{t-1} and x_t, outputs a value between 0 (completely forget) and 1 (completely keep) for each element of the cell state c_{t-1}.

Input Gate (i_t) + Candidate (C_t)
Activation: sigmoid (gate) + tanh (candidate)

The input gate decides which values to update. A tanh layer creates a candidate vector of new values. Together, they determine what new information to store in the cell state.

Cell State (c_t)
The memory highway · Linear interactions only

The cell state is updated by: (1) multiplying by the forget gate output (forgetting old info), then (2) adding the input gate output times the candidate (adding new info). This linear update allows gradients to flow easily through time.

Output Gate (o_t)
Activation: sigmoid · Filters cell state for output

Controls what parts of the cell state are output as the hidden state. The cell state is passed through tanh (scaling to [-1, 1]) and multiplied by the output gate's sigmoid to produce h_t.

Hidden State (h_t)
Shape: [batch_size, hidden_dim]

The output of the LSTM cell at time t. This is both passed to the next time step (recurrence) and used as the cell's output for downstream layers. For sequence-to-one tasks, only the final h_T is used.

Key Equations

Forget Gate

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$

Sigmoid output between 0 and 1. Values close to 0 mean "forget this", values close to 1 mean "keep this".

Input Gate + Candidate

$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$ $$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

The input gate decides which values to update. The candidate creates new potential values.

Cell State Update

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

Element-wise: forget old info (f_t * C_{t-1}), add new info (i_t * candidate). The ⊙ symbol denotes element-wise multiplication.

Output Gate + Hidden State

$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$ $$h_t = o_t \odot \tanh(C_t)$$

Filter the cell state through the output gate to produce the hidden state.

Parameter Count

$$\text{params} = 4 \times [(n_{input} + n_{hidden}) \times n_{hidden} + n_{hidden}]$$

Four weight matrices (one per gate + candidate), each connecting [h_{t-1}, x_t] to the hidden dimension.

Implementation

PyTorch

import torch
import torch.nn as nn

class LSTMModel(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim, num_layers=2):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            dropout=0.2
        )
        self.fc = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        # x shape: [batch, seq_len, input_dim]
        lstm_out, (h_n, c_n) = self.lstm(x)
        # Use last hidden state
        out = self.fc(h_n[-1])
        return out

# Example usage
model = LSTMModel(input_dim=10, hidden_dim=64, output_dim=1)
x = torch.randn(32, 20, 10)  # batch=32, seq_len=20, features=10
output = model(x)              # shape: [32, 1]

LSTM Cell from Scratch (NumPy)

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-np.clip(x, -500, 500)))

class LSTMCell:
    def __init__(self, input_dim, hidden_dim):
        scale = 0.01
        self.Wf = np.random.randn(input_dim + hidden_dim, hidden_dim) * scale
        self.Wi = np.random.randn(input_dim + hidden_dim, hidden_dim) * scale
        self.Wc = np.random.randn(input_dim + hidden_dim, hidden_dim) * scale
        self.Wo = np.random.randn(input_dim + hidden_dim, hidden_dim) * scale
        self.bf = np.zeros((1, hidden_dim))
        self.bi = np.zeros((1, hidden_dim))
        self.bc = np.zeros((1, hidden_dim))
        self.bo = np.zeros((1, hidden_dim))

    def forward(self, x, h_prev, c_prev):
        concat = np.concatenate([h_prev, x], axis=1)
        f = sigmoid(concat @ self.Wf + self.bf)      # forget gate
        i = sigmoid(concat @ self.Wi + self.bi)       # input gate
        c_hat = np.tanh(concat @ self.Wc + self.bc)   # candidate
        c = f * c_prev + i * c_hat                     # cell state
        o = sigmoid(concat @ self.Wo + self.bo)       # output gate
        h = o * np.tanh(c)                             # hidden state
        return h, c

cell = LSTMCell(input_dim=10, hidden_dim=64)
h = np.zeros((1, 64))
c = np.zeros((1, 64))
for t in range(20):
    x_t = np.random.randn(1, 10)
    h, c = cell.forward(x_t, h, c)

Key Papers

Long Short-Term Memory
Hochreiter & Schmidhuber, 1997 — The original LSTM paper introducing gated memory cells
Learning to Forget: Continual Prediction with LSTM
Gers, Schmidhuber & Cummins, 2000 — Added the forget gate to the original LSTM
Empirical Evaluation of Gated Recurrent Neural Networks on Sequence Modeling
Chung et al., 2014 — Comparison of LSTM and GRU variants
LSTM: A Search Space Odyssey
Greff et al., 2015 — Comprehensive analysis of LSTM variants and their components

Related Architectures

  • RNN — The simpler predecessor without gating mechanisms
  • GRU — A simplified variant with only two gates (reset and update)
  • Transformer — Attention-based alternative that processes sequences in parallel
