Overview

The Perceptron is the simplest form of a neural network, originally proposed by Frank Rosenblatt in 1958. It consists of a single layer of weights connecting inputs directly to outputs. While limited to linearly separable problems, it introduced the fundamental concepts of learnable weights and threshold activation.

The Multi-Layer Perceptron (MLP) extends this by stacking multiple fully-connected layers with non-linear activations, forming a universal function approximator. Trained via backpropagation (popularized by Rumelhart, Hinton, and Williams in 1986), the MLP became the foundation of modern deep learning.

Key Innovation

The combination of multiple layers with non-linear activation functions allows MLPs to learn complex, non-linear decision boundaries. The backpropagation algorithm enables efficient gradient computation through all layers, making training practical.

Common Use Cases

  • Classification — binary and multi-class classification tasks
  • Regression — continuous value prediction
  • Function approximation — learning arbitrary input-output mappings
  • Feature learning — hidden layers learn useful intermediate representations
  • Tabular data — structured data with fixed-size feature vectors

Limitations

  • No parameter sharing — every connection has its own weight (scales poorly to high-dimensional inputs)
  • No spatial or temporal structure awareness (unlike CNNs or RNNs)
  • Prone to overfitting without regularization on complex datasets
  • All inputs must be fixed-length vectors

Layer-by-Layer Breakdown

Input Layer
Shape: [batch_size, n_features]

The input layer receives raw feature vectors. Each neuron represents one feature of the input data. No learnable parameters — this layer simply passes data to the first hidden layer.

Hidden Layer 1 (Dense + ReLU)
Shape: [batch_size, hidden_units] · Params: n_features × hidden_units + hidden_units

The first hidden layer applies a linear transformation (weight matrix multiplication + bias) followed by a ReLU activation function. This introduces non-linearity, allowing the network to learn features beyond linear combinations of the input.

Hidden Layer 2 (Dense + ReLU)
Shape: [batch_size, hidden_units] · Params: hidden_units2 + hidden_units

A second hidden layer enables the network to compose higher-level features from the representations learned in the first hidden layer. Deeper networks can represent increasingly abstract features.

Pre-Output Layer (Dense + ReLU)
Shape: [batch_size, pre_output_units]

An additional layer that narrows the representation before the final output. This bottleneck forces the network to compress information into a smaller representation.

Output Layer (Dense + Sigmoid/Softmax)
Shape: [batch_size, n_classes]

The final layer produces the network's prediction. For binary classification, a single output with sigmoid activation gives a probability. For multi-class, softmax normalizes outputs into a probability distribution. For regression, no activation is used (linear output).

Key Equations

Single Neuron (Perceptron)

$$y = \sigma\left(\sum_{i=1}^{n} w_i x_i + b\right) = \sigma(\mathbf{w}^T \mathbf{x} + b)$$

Each neuron computes a weighted sum of its inputs plus a bias term, then applies an activation function σ.

Forward Pass (Layer l)

$$\mathbf{z}^{[l]} = \mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}$$ $$\mathbf{a}^{[l]} = g(\mathbf{z}^{[l]})$$

Where W is the weight matrix, a is the activation vector, b is the bias, and g is the activation function (ReLU, sigmoid, etc.).

ReLU Activation

$$\text{ReLU}(z) = \max(0, z)$$

Cross-Entropy Loss (Classification)

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\left[y_i \log(\hat{y}_i) + (1 - y_i)\log(1 - \hat{y}_i)\right]$$

Backpropagation (Weight Update)

$$\mathbf{W}^{[l]} \leftarrow \mathbf{W}^{[l]} - \alpha \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{[l]}}$$

Gradients flow backward through the chain rule. The learning rate α controls the step size.

Implementation

PyTorch

import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Linear(hidden_dim // 2, output_dim),
        )

    def forward(self, x):
        return self.layers(x)

# Example usage
model = MLP(input_dim=3, hidden_dim=4, output_dim=1)
x = torch.randn(32, 3)  # batch of 32, 3 features
output = model(x)        # shape: [32, 1]

TensorFlow / Keras

import tensorflow as tf
from tensorflow import keras

model = keras.Sequential([
    keras.layers.Dense(4, activation='relu', input_shape=(3,)),
    keras.layers.Dense(4, activation='relu'),
    keras.layers.Dense(2, activation='relu'),
    keras.layers.Dense(1, activation='sigmoid'),
])

model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)

NumPy (From Scratch)

import numpy as np

def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

class SimpleMLP:
    def __init__(self, layer_sizes):
        self.weights = []
        self.biases = []
        for i in range(len(layer_sizes) - 1):
            w = np.random.randn(layer_sizes[i], layer_sizes[i+1]) * 0.01
            b = np.zeros((1, layer_sizes[i+1]))
            self.weights.append(w)
            self.biases.append(b)

    def forward(self, x):
        a = x
        for i, (w, b) in enumerate(zip(self.weights, self.biases)):
            z = a @ w + b
            a = sigmoid(z) if i == len(self.weights)-1 else relu(z)
        return a

mlp = SimpleMLP([3, 4, 4, 2, 1])
out = mlp.forward(np.random.randn(1, 3))

Related Architectures

The MLP is the foundation upon which these architectures build:

  • CNN — Replaces dense layers with convolutional layers for spatial data
  • Autoencoder — MLP trained to reconstruct its input through a bottleneck
  • ResNet — Adds skip connections to enable much deeper networks
