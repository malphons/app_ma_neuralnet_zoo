Overview

The Convolutional Neural Network (CNN) is a class of deep neural networks designed to process data with a grid-like topology, such as images. First demonstrated at scale by Yann LeCun and colleagues in 1998 with LeNet-5, CNNs exploit the spatial structure of input data through learnable convolution filters that slide across the input, extracting local features at every position.

Unlike fully-connected networks where every input connects to every neuron, CNNs use local connectivity and parameter sharing: a small filter (kernel) is applied across the entire input, meaning the same weights detect the same feature regardless of its position. This gives CNNs translation invariance — a feature like an edge or a corner is detected wherever it appears in the image.

Key Innovation

CNNs introduced three critical ideas to neural network design:

  • Local receptive fields — each neuron connects only to a small region of the input, capturing local spatial patterns
  • Shared weights (convolution filters) — the same filter is reused across the entire input, dramatically reducing the parameter count compared to dense layers
  • Hierarchical feature learning — early layers learn low-level features (edges, textures), while deeper layers compose them into high-level concepts (shapes, objects)

Common Use Cases

  • Image classification — categorizing images into classes (e.g., ImageNet, CIFAR-10)
  • Object detection — locating and classifying objects within images (YOLO, Faster R-CNN)
  • Image segmentation — pixel-level classification for medical imaging, autonomous driving
  • Video analysis — action recognition, video captioning using 3D convolutions
  • Beyond vision — 1D convolutions for audio, text classification, and time-series data

Limitations

  • Not inherently suited for sequential or temporal data (RNNs and Transformers are preferred)
  • Large memory footprint for high-resolution images due to feature map storage
  • Pooling layers discard spatial precision, which can hurt tasks like fine-grained localization
  • Requires large labeled datasets to learn robust features without pre-training

Layer-by-Layer Breakdown

Input Layer (RGB Image)
Shape: [batch, 3, H, W]

The input layer receives a raw image as a 3D tensor: 3 color channels (Red, Green, Blue) with height H and width W. Each channel is a 2D grid of pixel intensities, typically normalized to [0, 1] or [-1, 1]. No learnable parameters — this layer simply feeds pixel data into the first convolution.

Conv1 + ReLU (Convolution Layer 1)
Shape: [batch, C1, H', W'] · Params: C1 × (K × K × 3 + 1)

The first convolutional layer applies C1 learnable filters (kernels) of size K×K across the input image. Each filter slides over the input, computing a dot product at each position to produce one feature map. The ReLU activation function is applied element-wise, zeroing out negative values. This layer typically detects low-level features such as edges, corners, and color gradients.

MaxPool1 (Max Pooling Layer 1)
Shape: [batch, C1, H'/2, W'/2] · Params: 0

Max pooling reduces spatial dimensions by taking the maximum value within a 2×2 window (stride 2). This provides a small degree of translation invariance, reduces computation for subsequent layers, and prevents overfitting by summarizing local regions. The number of feature maps (channels) remains unchanged.

Conv2 + ReLU (Convolution Layer 2)
Shape: [batch, C2, H'', W''] · Params: C2 × (K × K × C1 + 1)

The second convolution applies C2 filters over the pooled feature maps. Because the spatial dimensions are already reduced, these filters now have a larger effective receptive field over the original image. This layer learns to combine the low-level features from Conv1 into more complex patterns: shapes, textures, and parts of objects.

MaxPool2 (Max Pooling Layer 2)
Shape: [batch, C2, H''/2, W''/2] · Params: 0

A second round of max pooling further halves the spatial dimensions. At this point, each feature map is a compact summary of a large region of the original input, encoding whether specific mid-level features are present somewhere in that region.

Flatten + Dense (Fully Connected)
Shape: [batch, dense_units] · Params: (C2 × H'' × W'') × dense_units + dense_units

The 2D feature maps are flattened into a 1D vector and passed through a fully-connected (dense) layer with ReLU activation. This layer acts as the classification head, combining spatial features from across the image into a global representation. This is where the network learns which combinations of features correspond to each class.

Output Layer (Dense + Softmax)
Shape: [batch, n_classes]

The final layer has one neuron per class. A softmax activation converts the raw logits into a probability distribution over all classes, where each output is between 0 and 1 and all outputs sum to 1. The predicted class is the one with the highest probability.

Key Equations

2D Convolution Operation

$$(f * g)(i,j) = \sum_m \sum_n f(m,n) \cdot g(i-m, j-n)$$

The convolution operator slides a kernel g over the input f, computing the sum of element-wise products at each position (i, j). In practice, deep learning frameworks use cross-correlation (without flipping the kernel), but the term "convolution" is used by convention.

Output Spatial Size

$$O = \frac{W - K + 2P}{S} + 1$$

Where W is the input width (or height), K is the kernel size, P is the padding, and S is the stride. This formula determines the spatial dimensions of each feature map after a convolution or pooling operation.

ReLU Activation

$$\text{ReLU}(z) = \max(0, z)$$

The Rectified Linear Unit introduces non-linearity by zeroing out negative values. It is computationally efficient and helps mitigate the vanishing gradient problem in deep networks.

Softmax Output

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

Softmax converts the raw output logits into a probability distribution across K classes.

Cross-Entropy Loss

$$\mathcal{L} = -\sum_{i=1}^{K} y_i \log(\hat{y}_i)$$

The standard loss function for multi-class classification. It measures how far the predicted probability distribution is from the true one-hot label. Lower loss means better predictions.

Implementation

PyTorch

import torch
import torch.nn as nn

class CNN(nn.Module):
    def __init__(self, num_classes=2):
        super().__init__()
        self.features = nn.Sequential(
            # Conv1: 3 input channels -> 16 feature maps, 3x3 kernel
            nn.Conv2d(3, 16, kernel_size=3, padding=1),  # [B, 16, H, W]
            nn.ReLU(),
            nn.MaxPool2d(2, 2),                           # [B, 16, H/2, W/2]

            # Conv2: 16 -> 32 feature maps
            nn.Conv2d(16, 32, kernel_size=3, padding=1),  # [B, 32, H/2, W/2]
            nn.ReLU(),
            nn.MaxPool2d(2, 2),                           # [B, 32, H/4, W/4]
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),                                  # [B, 32*H/4*W/4]
            nn.Linear(32 * 8 * 8, 64),                    # assuming 32x32 input
            nn.ReLU(),
            nn.Linear(64, num_classes),                    # [B, num_classes]
        )

    def forward(self, x):
        x = self.features(x)     # spatial feature extraction
        x = self.classifier(x)   # classification head
        return x

# Example: 32x32 RGB images, 2 classes
model = CNN(num_classes=2)
x = torch.randn(8, 3, 32, 32)   # batch of 8 images
logits = model(x)                # shape: [8, 2]
probs = torch.softmax(logits, dim=1)

TensorFlow / Keras

import tensorflow as tf
from tensorflow import keras

model = keras.Sequential([
    # Conv1 + Pool1
    keras.layers.Conv2D(16, (3, 3), activation='relu',
                        padding='same', input_shape=(32, 32, 3)),  # [B, 32, 32, 16]
    keras.layers.MaxPooling2D((2, 2)),                             # [B, 16, 16, 16]

    # Conv2 + Pool2
    keras.layers.Conv2D(32, (3, 3), activation='relu',
                        padding='same'),                           # [B, 16, 16, 32]
    keras.layers.MaxPooling2D((2, 2)),                             # [B, 8, 8, 32]

    # Classification head
    keras.layers.Flatten(),                                        # [B, 2048]
    keras.layers.Dense(64, activation='relu'),                     # [B, 64]
    keras.layers.Dense(2, activation='softmax'),                   # [B, 2]
])

model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

Key Papers

Gradient-Based Learning Applied to Document Recognition
LeCun, Bottou, Bengio & Haffner, 1998 — The LeNet-5 paper: the foundational CNN architecture for handwritten digit recognition
ImageNet Classification with Deep Convolutional Neural Networks
Krizhevsky, Sutskever & Hinton, 2012 — AlexNet: sparked the deep learning revolution by winning ImageNet with a large CNN using GPUs, ReLU, and dropout
Very Deep Convolutional Networks for Large-Scale Image Recognition
Simonyan & Zisserman, 2014 — VGGNet: demonstrated that depth (16-19 layers) with small 3×3 filters consistently improves performance
Deep Residual Learning for Image Recognition
He, Zhang, Ren & Sun, 2015 — ResNet: introduced skip connections enabling training of 100+ layer CNNs

Related Architectures

CNNs serve as the backbone for many specialized architectures:

  • ResNet — Adds residual (skip) connections to enable training of very deep CNNs without degradation
  • U-Net — Encoder-decoder CNN with skip connections, widely used in image segmentation
  • AlexNet — The pioneering deep CNN that demonstrated GPU-accelerated training at scale
