Overview

The Generative Adversarial Network (GAN), introduced by Goodfellow et al. in 2014, revolutionized generative modeling through an adversarial training framework. Two neural networks — a Generator and a Discriminator — are trained simultaneously in a minimax game.

The Generator learns to produce realistic data from random noise, while the Discriminator learns to distinguish real data from generated fakes. Through this adversarial process, the Generator progressively improves until its outputs are indistinguishable from real data.

Key Innovation

The adversarial training framework eliminates the need for explicit density estimation or reconstruction losses. The Discriminator provides a learned loss function that adapts as the Generator improves, enabling the generation of remarkably realistic data.

Common Use Cases

  • Image generation — photorealistic face synthesis, art creation
  • Style transfer — converting images between domains (CycleGAN)
  • Data augmentation — generating synthetic training data
  • Super-resolution — enhancing image resolution (SRGAN)
  • Image inpainting — filling in missing regions of images

Limitations

  • Training instability — mode collapse, vanishing gradients
  • No explicit density estimation (cannot evaluate likelihood)
  • Difficult to evaluate generation quality objectively
  • Balancing Generator and Discriminator training is challenging

Noise Input (z)
Shape: [batch_size, latent_dim] · Sampled from N(0, 1)

Random noise vector sampled from a prior distribution (typically Gaussian). This is the seed from which the Generator creates fake data. Different noise vectors produce different generated samples.

Generator Hidden Layers
Dense + BatchNorm + ReLU · Progressively upscales

The Generator transforms random noise through a series of layers that progressively increase dimensionality. Batch normalization stabilizes training. For images, transposed convolutions upsample spatial dimensions.

Generator Output (Fake Data)
tanh activation · Same shape as real data

The Generator's output, shaped to match real data dimensions. tanh activation maps outputs to [-1, 1]. This fake data is fed to the Discriminator alongside real data for evaluation.

Discriminator Hidden Layers
Dense + LeakyReLU + Dropout

The Discriminator processes both real and fake data through feature extraction layers. LeakyReLU (instead of ReLU) prevents dead neurons. Dropout provides regularization. For images, strided convolutions downsample.

Discriminator Output (Real/Fake)
Sigmoid · P(real) in [0, 1]

A single output representing the probability that the input is real. Values near 1 mean "real", near 0 mean "fake". The Discriminator tries to output 1 for real data and 0 for generated data.

Key Equations

Minimax Objective

$$\min_G \max_D \; \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

The Generator minimizes while the Discriminator maximizes. D tries to correctly classify real vs. fake; G tries to fool D.

Discriminator Loss

$$\mathcal{L}_D = -\mathbb{E}_{x \sim p_{data}}[\log D(x)] - \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

Maximize log-probability of correct classification for both real and fake data.

Generator Loss

$$\mathcal{L}_G = -\mathbb{E}_{z \sim p_z}[\log D(G(z))]$$

In practice, we maximize log D(G(z)) instead of minimizing log(1 - D(G(z))) for better gradients early in training.

Optimal Discriminator

$$D^*(x) = \frac{p_{data}(x)}{p_{data}(x) + p_g(x)}$$

At optimality, D outputs 0.5 everywhere, meaning G perfectly matches the data distribution.

Nash Equilibrium

$$p_g = p_{data} \implies D^*(x) = \frac{1}{2} \; \forall x$$

Implementation

PyTorch

import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, latent_dim=100, output_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.BatchNorm1d(256),
            nn.ReLU(),
            nn.Linear(256, 512),
            nn.BatchNorm1d(512),
            nn.ReLU(),
            nn.Linear(512, output_dim),
            nn.Tanh(),
        )

    def forward(self, z):
        return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, input_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Dropout(0.3),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Dropout(0.3),
            nn.Linear(256, 1),
            nn.Sigmoid(),
        )

    def forward(self, x):
        return self.net(x)

# Training loop sketch
G = Generator()
D = Discriminator()
criterion = nn.BCELoss()
opt_G = torch.optim.Adam(G.parameters(), lr=0.0002)
opt_D = torch.optim.Adam(D.parameters(), lr=0.0002)

TensorFlow / Keras

import tensorflow as tf
from tensorflow import keras

def build_generator(latent_dim=100):
    return keras.Sequential([
        keras.layers.Dense(256, input_shape=(latent_dim,)),
        keras.layers.BatchNormalization(),
        keras.layers.ReLU(),
        keras.layers.Dense(512),
        keras.layers.BatchNormalization(),
        keras.layers.ReLU(),
        keras.layers.Dense(784, activation='tanh'),
    ])

def build_discriminator():
    return keras.Sequential([
        keras.layers.Dense(512, input_shape=(784,)),
        keras.layers.LeakyReLU(0.2),
        keras.layers.Dropout(0.3),
        keras.layers.Dense(256),
        keras.layers.LeakyReLU(0.2),
        keras.layers.Dropout(0.3),
        keras.layers.Dense(1, activation='sigmoid'),
    ])

G = build_generator()
D = build_discriminator()
D.compile(optimizer='adam', loss='binary_crossentropy')

Training Loop (PyTorch)

# Inside training loop:
for real_data in dataloader:
    batch_size = real_data.size(0)
    real_labels = torch.ones(batch_size, 1)
    fake_labels = torch.zeros(batch_size, 1)

    # Train Discriminator
    z = torch.randn(batch_size, 100)
    fake_data = G(z).detach()
    d_real = D(real_data)
    d_fake = D(fake_data)
    loss_D = criterion(d_real, real_labels) + criterion(d_fake, fake_labels)
    opt_D.zero_grad()
    loss_D.backward()
    opt_D.step()

    # Train Generator
    z = torch.randn(batch_size, 100)
    fake_data = G(z)
    d_fake = D(fake_data)
    loss_G = criterion(d_fake, real_labels)  # fool D
    opt_G.zero_grad()
    loss_G.backward()
    opt_G.step()
