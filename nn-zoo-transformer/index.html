Overview

The Transformer, introduced by Vaswani et al. in 2017, replaced recurrence with self-attention, enabling fully parallel sequence processing. This architectural breakthrough powers virtually all modern large language models (GPT, BERT, etc.) and has expanded to vision, audio, and multi-modal tasks.

The key mechanism is scaled dot-product attention, where each element in a sequence attends to all other elements simultaneously. Combined with positional encoding to inject sequence order information, Transformers can model long-range dependencies without the sequential bottleneck of RNNs.

Key Innovation

Self-attention allows every position to directly attend to every other position in constant depth, unlike RNNs which require O(n) steps. Multi-head attention enables the model to attend to information from different representation subspaces simultaneously.

Common Use Cases

  • Machine translation — the original application (encoder-decoder Transformer)
  • Text generation — GPT-style autoregressive language models
  • Language understanding — BERT-style bidirectional encoding
  • Computer vision — Vision Transformer (ViT) for image classification
  • Multi-modal — combining text, image, and audio processing

Limitations

  • Quadratic memory and compute cost in sequence length O(n²)
  • No inherent notion of position (requires positional encoding)
  • Requires large amounts of training data to generalize well
  • Computationally expensive for very long sequences

Layer-by-Layer Breakdown

Click on any layer in the diagram above to highlight its description below.

Input Embedding
Shape: [batch_size, seq_len, d_model]

Converts input tokens (integers) into dense vector representations of dimension d_model. For text, this is a learned embedding matrix. The embeddings are scaled by the square root of d_model to maintain appropriate magnitude.

Positional Encoding
Added (not concatenated) to embeddings

Since Transformers have no recurrence or convolution, positional encodings inject information about token positions. The original paper uses sinusoidal functions of different frequencies, enabling the model to learn relative positions and generalize to unseen sequence lengths.

Multi-Head Self-Attention
h heads · Q, K, V projections · Scaled dot-product

The core of the Transformer. Input is projected into Queries (Q), Keys (K), and Values (V). Attention weights are computed as softmax(QK^T / sqrt(d_k)). Multiple attention heads allow attending to different aspects of the input simultaneously. Outputs are concatenated and linearly projected.

Feed-Forward Network
Two linear layers with ReLU · Applied position-wise

A two-layer fully-connected network applied independently to each position. Typically expands the dimension (d_model to 4*d_model) then projects back. This provides the non-linear transformation capacity that attention alone cannot.

Add & Layer Normalization
Residual connection + LayerNorm

Each sub-layer (attention, FFN) is wrapped in a residual connection followed by layer normalization: LayerNorm(x + Sublayer(x)). This stabilizes training and enables very deep stacking of encoder/decoder blocks.

Output Projection
Linear + Softmax · Shape: [batch_size, seq_len, vocab_size]

A linear projection from d_model to vocabulary size, followed by softmax to produce token probabilities. For encoder-only models (BERT), this may be a classification head instead.

Key Equations

Scaled Dot-Product Attention

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

Queries and Keys determine attention weights via dot product, scaled by sqrt(d_k) to prevent softmax saturation. Values are weighted by these attention scores.

Multi-Head Attention

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W^O$$ $$\text{where } \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

Each head projects Q, K, V into a subspace. Heads are concatenated and projected, allowing the model to jointly attend to information from different representation subspaces.

Positional Encoding

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$ $$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

Sinusoidal functions of different frequencies encode absolute position. For any fixed offset k, PE(pos+k) can be represented as a linear function of PE(pos).

Feed-Forward Network

$$\text{FFN}(x) = \text{ReLU}(xW_1 + b_1)W_2 + b_2$$

Layer Normalization

$$\text{LayerNorm}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$$

Implementation

Scaled Dot-Product Attention (PyTorch)

import torch
import torch.nn as nn
import math

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = torch.softmax(scores, dim=-1)
    return torch.matmul(weights, V), weights

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, num_heads=8):
        super().__init__()
        self.d_k = d_model // num_heads
        self.num_heads = num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, Q, K, V, mask=None):
        batch = Q.size(0)
        Q = self.W_q(Q).view(batch, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_k(K).view(batch, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_v(V).view(batch, -1, self.num_heads, self.d_k).transpose(1, 2)
        out, _ = scaled_dot_product_attention(Q, K, V, mask)
        out = out.transpose(1, 2).contiguous().view(batch, -1, self.num_heads * self.d_k)
        return self.W_o(out)

Transformer Encoder Block (PyTorch)

class TransformerBlock(nn.Module):
    def __init__(self, d_model=512, num_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model),
        )
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        attn_out = self.attention(x, x, x, mask)
        x = self.norm1(x + self.dropout(attn_out))
        ffn_out = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_out))
        return x

TensorFlow / Keras

import tensorflow as tf
from tensorflow import keras

# Using built-in MultiHeadAttention
class TransformerBlock(keras.layers.Layer):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.att = keras.layers.MultiHeadAttention(
            num_heads=num_heads, key_dim=d_model // num_heads
        )
        self.ffn = keras.Sequential([
            keras.layers.Dense(d_ff, activation='relu'),
            keras.layers.Dense(d_model),
        ])
        self.norm1 = keras.layers.LayerNormalization()
        self.norm2 = keras.layers.LayerNormalization()
        self.drop1 = keras.layers.Dropout(dropout)
        self.drop2 = keras.layers.Dropout(dropout)

    def call(self, x, training=False):
        attn = self.att(x, x)
        x = self.norm1(x + self.drop1(attn, training=training))
        ffn = self.ffn(x)
        return self.norm2(x + self.drop2(ffn, training=training))
